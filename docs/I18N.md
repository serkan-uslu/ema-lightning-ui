# Internationalisation

The UI ships in **Turkish** (default) and **English**.

## How it works

- `src/i18n/tr.ts` is the source dictionary and defines the `Dictionary` type.
- `src/i18n/en.ts` is typed as `Dictionary`, so a missing or misspelled key is a TypeScript error.
- Strings that need values are functions, e.g. `editor.selected: (n) => \`${n} selected\``.
- `I18nProvider` stores the choice in the `ema-locale` cookie. The root layout reads it on the server, so the first render, `<html lang>` and the page title are already in the right language.
- Users switch language from the top bar or **Settings**.

```tsx
const { t, locale } = useI18n();
return <h1>{t.queue.title}</h1>;
```

Dates and numbers use `formatShortDate`, `formatTime` and `formatNumber` from `src/lib/format.ts` with the active locale.

## Backend messages

FastAPI returns Turkish `detail` messages. `describeError()` (for thrown errors) and `translateBackend()` (for stored job/model errors) look the exact Turkish text up in `en.backendErrors`. Unknown messages are shown as-is. When you add or change an `HTTPException` message in `backend/app.py`, update `backendErrors` too.

Job labels are generated by the backend from paragraph text or the project name and are not translated.

## Adding a language

1. Add the code to `locales` in `src/i18n/config.ts`.
2. Create `src/i18n/<code>.ts` typed as `Dictionary` and register it in `src/i18n/index.ts`.
3. Add the Intl locale to `src/lib/format.ts` and an option to `LanguageSwitch`.
